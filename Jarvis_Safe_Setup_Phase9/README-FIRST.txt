JARVIS PHASE 9 - DESKTOP APP

Run Setup-Jarvis-Phase9.ps1 once. Then launch:
  %LOCALAPPDATA%\Jarvis\Phase9\Start-Jarvis-App.cmd

The window starts the already-tested Jarvis core automatically. Closing the window
hides it in the notification area. Use the tray icon to show, start, stop, or fully
exit Jarvis.

This phase does not add administrator access or broaden Jarvis's action allowlist.

JARVIS PHASE 2 - HEY JARVIS
============================

Phase 2 installs the actual local Hey Jarvis listener. It does not add speech
transcription, an AI connection, memory, spoken replies, or Windows startup yet.

Installed location:
  %LOCALAPPDATA%\Jarvis\Phase2

Tomorrow's live test:
1. Open %LOCALAPPDATA%\Jarvis\Phase2
2. Double-click Test-Hey-Jarvis.cmd
3. Say "Hey Jarvis" several times during the 60-second test
4. Look for HEY JARVIS DETECTED and WAKE LISTENER TEST PASSED

To run the listener manually afterward, double-click Start-Hey-Jarvis.cmd.
Press Ctrl+C in its window to stop it.

Phase 2 does not start automatically with Windows. That will only be added in a
later polish phase after the listener is tuned and explicitly approved.

JARVIS PHASE 8 - SAFE WINDOWS ACTIONS
=====================================

Allowed local voice actions:
- Open Notepad
- Open Calculator
- Open File Explorer
- Open Settings
- Open Task Manager

The parser is local and strictly allowlisted. Gemini cannot construct or execute
shell commands. File deletion, closing apps, shutdown/restart, PowerShell, command
prompt, registry changes, and unlisted programs are not executable in Phase 8.

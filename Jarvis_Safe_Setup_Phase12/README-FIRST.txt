JARVIS PHASE 12 - YOUTUBE AUTO SKIP

This local Opera GX extension clicks YouTube's available Skip button and uses
SponsorBlock's privacy-preserving hash-prefix API to skip community-verified sponsor
and self-promotion segments. Unskippable ads remain unskippable.

Enable it once in Opera GX:
1. Open opera://extensions
2. Turn on Developer mode
3. Choose Load unpacked
4. Select: %LOCALAPPDATA%\Jarvis\Phase12\YouTube-Auto-Skip

It requests access only to YouTube and the SponsorBlock API.
